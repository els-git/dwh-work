# I04 — PostgreSQL-коннектор: план (ПРОЕКТ)

**Статус документа:** проект от 04.11.2026, ждёт утверждения пользователя.
**Статус задачи:** I04 `PLANNED`.
**Решение пользователя 04.11.2026 (вариант A):** рубеж SecretStore для I04 считается пройденным для работы с **синтетическими** учётными данными (ключи закрыты I02-05). Чтение учётных данных (READ) делается и принимается внутри I04; **настоящий пароль вводится только после приёмки READ** (шаг 7). Восстановление после сбоя и конкурентность — I13-04.

## 1. Что получится в итоге

1. В панели «Подключение» источника PostgreSQL — кнопка «Проверить подключение»: сервер расшифровывает учётные данные, подключается к источнику **только на чтение**, показывает результат без паролей и строк подключения. Успешная проверка переводит подключение в `READY`.
2. Каждое чтение учётных данных записывается в журнал `secret_store` (операция `READ`, кто и когда).
3. Можно посмотреть схемы и таблицы источника и сохранить снимок структуры таблицы: колонки, типы, nullable, первичный ключ.
4. Для `OPERATION_COLLECTOR` сохранён снимок `public.asan_pension_requests` (I04-03).
5. Действующий CRM ETL работает как раньше (I04-04), пароль CRM перенесён из `.env` в SecretStore (I04-05).

## 3. Решения для утверждения

| № | Вопрос | Рекомендация |
|---|---|---|
| Р1 | Кто проверяет подключение | backend по запросу администратора (`SUPERADMIN`/`ADMIN`), не ETL |
| Р2 | Где хранить результат проверки | в `meta.source_connection`: время, успех, краткий код ошибки; `READY` — только при успешной последней проверке |
| Р3 | Где хранить снимок структуры | существующие `meta.source_object_snapshot` / `meta.source_column_snapshot`, если структура подходит (проверяется на шаге 2); иначе — отдельное решение |
| Р4 | Что читается из источника | только каталог (`pg_catalog`/`information_schema`); строки данных в I04 не читаются; лимит списка объектов (например, 5000) |
| Р5 | Настоящий пароль | только после шага 6 и отдельного утверждения пользователя (шаг 7) |
| Р6 | Перенос пароля CRM (I04-05) | последним блоком I04, с отдельным разрешением на изменение ETL и запуск регрессии |
