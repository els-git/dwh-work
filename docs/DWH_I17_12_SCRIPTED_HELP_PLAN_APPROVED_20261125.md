## 1. Задача

Вопросы о том, как пользоваться приложением, отвечать скриптом по справке — сразу, без модели, как чатбот сайта `els-git/evas-forge-site` (правила «слова → готовый ответ + ссылка»). Модели оставить отчёты по описанию (SQL), снимки экрана и разбор ошибок, который не покрывает шаблон. Цель — разгрузить модель: сейчас ответ по справке занимает минуты (25.11.2026: 329 с, из них 307 с модель читала запрос в 2379 токенов, 7,7 ток/с).

## 2. Что уже есть

- Поиск разделов справки с учётом роли — код (`ai_knowledge.KnowledgeIndex.search`), миллисекунды; модель только пересказывает найденное.
- С выпуска `2026.11.69` модели уходят только строки разделов со словами вопроса (`ai_core.trim_found`, до 2400 знаков) — это и есть готовый «скриптовый» ответ.
- Разбор ошибки (I17-10): сначала мгновенная карточка из досье и базы знаний 33 кодов (`ai_diagnosis.card`, `card_only`), затем — пересказ моделью.
