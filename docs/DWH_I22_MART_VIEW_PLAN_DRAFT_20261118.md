# I22 «Просмотр витрин в Отчётности» — проект плана

Статус: **проект, ждёт утверждения** (18.11.2026). ID I22 и I23 и порядок «сначала I22, затем I23» согласованы пользователем 18.11.2026.

## 1. Требование пользователя

«В отчётности должна быть возможность вывода ДМ» — открыть опубликованную витрину прямо в «Отчётности», без ИИ-помощника.

## 2. Что уже есть (проверено по коду 18.11.2026)

- Публикация витрины ведёт строку белого списка `meta.ai_report_object` с правом витрины (`required_permission_code`, по умолчанию `REPORT_VIEW`) — пакеты 018/019.
- `app.saved_report_allowed_objects(token)` (пакет 017) возвращает витрины, разрешённые сессии: нужен `REPORT_VIEW` и право витрины.
- Роль `dwh_ai_ro` читает всю `dm`, только `SELECT`; подключение `db.connect_ai_readonly` (пароль `DWH_AI_DB_PASSWORD`).
- «Отчётность» сейчас — только вкладка «Мои и общие отчёты» (`SavedReportsPanel.tsx`).
- Журнал `app.ai_request_log` принимает виды `HELP`, `REPORT`, `SAVED_REPORT`; вида для просмотра витрины нет.

## 3. Решения (на утверждение)

| № | Вопрос | Рекомендация | Вариант |
|---|---|---|---|
| В1 | Где | «Отчётность» → новая вкладка **«Витрины»**: список разрешённых роли витрин (название, код, описание, время последнего построения) | — |
| В2 | Как читаются данные | API строит запрос сам, только по витрине из разрешённого списка и колонкам её таблицы; пользовательского SQL нет; значения фильтров — параметры; роль `dwh_ai_ro`, только чтение, `statement_timeout` 60 с | — |
| В3 | Таблица | Постранично по 100 строк, общее число строк, сортировка по колонке, фильтры по колонкам: «равно», «содержит» (текст), «от / до» (числа и даты), «пусто / не пусто» | — |
| В4 | Выгрузка | «Скачать CSV» — все строки по текущим фильтрам, потоком, UTF-8 с BOM (открывается в Excel), предел 1 000 000 строк с предупреждением | B — ещё Excel (.xlsx), дольше и тяжелее для больших витрин |
| В5 | Журнал | **A** — каждое открытие и выгрузка пишутся в `app.ai_request_log` видом `MART_VIEW` (кто, витрина, фильтры, строк, выгрузка да/нет): пакет **022** — вид журнала и функции `app.mart_view_begin/_finish` | B — без журнала и без пакета |
| В6 | Сохранить вид с фильтрами в «Мои и общие отчёты» | **B — не в I22** (отдельной задачей при необходимости) | A — в пакете 022 функция сохранения вида |

При В5 = A номер пакета витрины по SQL (I23) — **023**.

## 4. Шаги до `DONE`

1. Утверждение плана (В1–В6).
2. Пакет 022 (если В5 = A): E0 в песочнице → E1 на копии → E2 к `dwh`, каждый переход с разрешения.
3. Песочница: API `/api/reports/marts` (список, страница, CSV), вкладка «Витрины», тексты ru/en/az, справка 3.5; тесты, сборка, ESLint 0/0, проверка в браузере (администратор и «аудит»).
4. Выпуск на сервер, приёмка: `cdp_clients` открывается, фильтр и сортировка, CSV, «аудит» не видит закрытую витрину, запись в журнале; реестр.
5. `DONE` после подтверждения пользователя.

## 5. Не входит

Изменение витрин и их данных; пользовательский SQL (это I23); графики и сводные таблицы.
