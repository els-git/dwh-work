# I03-05 — Изменение схемы и имени неиспользуемого объекта источника

<sub>Проект плана · 20.11.2026 · на утверждение пользователя</sub>

## 1. Задача

Требование пользователя (20.11.2026, `PROCESS_VIEWER`): объект, зарегистрированный с ошибкой (`app_users.services` вместо `public.services`), нельзя исправить — в форме «Изменить» доступны только тип объекта и описание. **Пока объект не используется, должна быть возможность изменить его схему и имя.**

Причина: функция базы `app.integration_source_object_update` (старый контур, текста нет в git) не принимает систему, схему и имя; форма лишь повторяет это. Идентичность используемого объекта менять нельзя — к ней привязаны снимки, версии маппинга, таблицы STG/ODS и история загрузок.

**Критерий:** у неиспользуемого объекта в «Изменить» схема и имя доступны и сохраняются (с записью в аудит); у используемого — недоступны, база отказывает понятной причиной.

## 2. Что значит «используется» (по каталогу песочницы; на сервере сверяется шагом 2)

На `meta.source_object` ссылаются внешними ключами: `meta.source_object_snapshot`, `meta.object_config_version` / `_current`, `meta.object_ods_version` / `_current`, `meta.target_change_proposal`, `etl.object_run`, `etl.object_ods_run`, `etl.object_run_request`, `etl.job`, `etl.error_log`.

## 3. Решения (на утверждение)

| № | Вопрос | Рекомендация | Другой вариант |
|---|---|---|---|
| О1 | Когда объект «не используется» | **A** — нет ни одной строки ни в одной таблице, ссылающейся на него внешним ключом; список берётся из каталога базы при каждой проверке, поэтому будущие таблицы учитываются сами | B — фиксированный список таблиц в функции |
| О2 | Что можно менять | **A** — схему и имя; исходную систему — нет (это уже другой объект другого источника — создать новый) | B — и исходную систему |
| О3 | Удаление ошибочного неиспользуемого объекта | **A** — да: кнопка «Удалить» вместо «Отключить», только пока не используется, с записью в аудит | B — нет, только «Отключить» (ошибочные записи остаются в списке) |
| О4 | Повтор имени | **A** — отказ, если у той же системы уже есть объект с такой схемой и именем | B — без проверки |

## 4. Шаги до `DONE`

3. **Песочница:** пакет 028 (новые функции `app.integration_source_object_rename` и, по О3, `_delete`; проверка «используется» по каталогу; аудит; права только `dwh_app`; старая функция изменения не меняется), E0; API (`PUT …/source-objects/{id}/identity`, признак `in_use` в списке) и форма (поля доступны при `in_use = false`); тесты, сборка, ESLint 0/0, браузер.
